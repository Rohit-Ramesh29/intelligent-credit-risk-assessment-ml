# Intelligent Credit Risk Assessment System

An AI-powered credit risk classification system that predicts whether a loan applicant belongs to Low, Medium, or High Risk categories using supervised and ensemble machine learning techniques.

## Features
- Exploratory Data Analysis (EDA)
- Decision Tree, Random Forest, Gradient Boosting
- Cross-validation model comparison
- Feature importance analysis
- Scalable ML pipeline

## Tech Stack
Python, Pandas, NumPy, Scikit-learn, Matplotlib, Seaborn, XGBoost

## Business Impact
- Faster loan approval
- Reduced financial risk
- Data-driven credit decisions
